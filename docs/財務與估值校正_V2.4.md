# 財務與估值校正 V2.4

日期：2026-10-12。此版本修正資料與期間計算，正式 Top 原有流動性、事件風險、法人轉賣、過熱與分散門檻維持。

## 已修正

- TWSE 與 TPEx 官方全市場 PER/PBR 為首選；必須與候選股價資料日一致。不同日期的估值不混用。
- 官方估值沒有該檔或欄位時，才使用可驗證的 MOPS 資料回推。官方 PER 未提供且無正值 TTM 依據，不拿正值累計 EPS 填成便宜股。
- 第二季累計 EPS 年化乘二、第三季乘 4/3、第四季不再乘四。年化值是估算，並非公司獲利預測。
- PBR 回推使用股價除官方每股參考淨值，移除 PER 乘 ROE 的混算。
- ROE 使用相同範圍的淨利與權益，母公司與合併總額不混搭。缺少平均權益時，明示期末權益年化估算；有完整歷史才使用 TTM 淨利及平均權益。
- 保存最多 16 個財務期間，不因同季每天刷新就丟掉比較基準。當年 Q1、Q2 累計 EPS 不再互相當成 QoQ 比較。
- EPS 加速只用已存在的同年季比較資料。缺少去年同季不能當作前期 EPS 為零／虧損，也不再用營收成長代理 EPS 加速。
- 補充官方銀行、金控、保險、證券期貨及異業資產負債表分類。金融業不套用一般企業的低負債加分規則。
- LINE 與 Gemini 資料包含期間及估算標記；詳細缺漏／官方覆蓋率寫入財務健檢快取與 Actions artifact。

## 尚未宣稱完成的部分

官方最新 CSV 只提供目前報告期間。初次建立歷史時，沒有去年同季資料的 EPS 比較仍是「不足」，不是成長零，也不是已驗證的轉盈。

TTM EPS 若由「去年全年 + 今年累計 - 去年同期」銜接，仍標為估算，因各期 EPS 的加權平均股數可能不同。若需精確單季 EPS、復權後 EPS 成長及回測，還需回補官方多期報表、公司股本變動與公告日期。

ROE 估算不是官方公布的完整財務分析 ROE；缺值不偽造。金融業監理資本、逾放與保險風險，亦不能由一般企業負債比代替。

營收多月持續性、全候選現金流、公告／法說會發現入口、產業基準與漏網稽核，列為下一階段。資料校正會讓等級與排序改變，不代表策略已通過績效回測或已能預測黑馬。
